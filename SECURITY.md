# Security policy

Masthead reads local agent logs that can contain private code, prompts and file paths,
so we take security reports seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub's
**Security → Report a vulnerability** form on this repository. Include steps to
reproduce and the version you tested.

We aim to acknowledge reports within a few days and will keep you updated until a fix
is released.

## Scope

In scope: anything that lets Masthead leak log contents, write to or execute files it
shouldn't, or be controlled by another process or web page.
